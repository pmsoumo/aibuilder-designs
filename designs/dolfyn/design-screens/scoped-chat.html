Scoped chat — @mention note selection

A chat session carries a scope: a list of notes. Empty scope is today's whole-corpus chat. One note is single-note mode. Two or more is multi-note. Cap is 5 notes.

Selection lives at the input, not at the top of the panel. Typing @ right after whitespace or at the start of the input opens a live-filtered note picker. Picking a note drops a chip into a slim row directly above the text field — inside the same composer bar, not a separate accent-tinted header. No standalone "+ Add note" button; @ is the only way in. "Chat about this note" still pre-seeds the first chip before the panel opens.
