Scoped chat — single & multi-note

A chat session carries a scope: a list of notes. Empty scope is today's whole-corpus chat. One note is single-note mode. Two or more is multi-note. Same mechanism at every size — scope grows by attaching, never by a separate flow. Cap is 5 notes.

Scope is optional, never required. A chat with no scope is exactly today's ambient chat, with no extra UI — see state 0. The scope bar only exists once a note is attached, and disappears again when the last one is removed.
