State A — Universal default (canvas-first)

The default composition for EVERY user on open — first-login and returning alike. Only the note canvas opens: the Notes and Chat side panels are closed by default; bottom navigation follows §4.12 (visible once notes exist). No top-right Notes/Chat header controls are shown; they were not intended. A stored panel preference wins across refresh (BUG-007). Panels open only on existing intentional actions — the focused canvas is the whole point.

What makes a great first-time user experience?

What makes a great first-time user experience? I've been thinking about this all week, mostly in the context of dolfyn but the question is bigger than that.

A great first-time experience doesn't explain. It doesn't onboard. It just lets the user do the thing they came to do, and shows them a glimpse of why it was worth coming.

The empty canvas is the onboarding. The blinking cursor is the invitation. The first note saved is the investment that makes the second visit more valuable than the first.

State F — Chat tab empty state (no notes yet)

The user navigated to the Chat tab before writing a note. The chat shows a defensive empty state: "Write your first note and I'll have something to talk about. Tap the Notes tab to get started." No input bar is shown — the user must write a note first. No AI presence bar — the chat has nothing to offer without notes. The Notes tab is the escape hatch. This state exists because the AI has nothing to retrieve without notes — the empty state is honest about that.

State G — Chat tab with existing conversation
