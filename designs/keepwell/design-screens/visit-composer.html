Visit composer — the note and the prescription in one pass

The rule this screen exists to prove: structure at the section level, freedom inside it. The headings are what make a printed prescription look professional. Fields are what make a doctor abandon the software. So only three things here are real fields — vitals, Rx rows, and the follow-up date — because only those three need to be machine-readable, for trends, for favourites, and for the recall that books itself. Everything else is prose under a printed heading. One save writes the visit record and renders the Rx; the doctor never writes a note and then writes a prescription.
